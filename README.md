# Room Temperature
## я netson, и недавно решил занятся ардуино

 этот проект я сделал ради интереса, он меряет комнатную температуру. если температура комнаты достаточно _теплая_, то горит зеленый диод, все что ниже или выше - красный

 I made this project out of curiosity, it measures the room temperature. if the room temperature is warm enough, the green diode lights up, and if it's lower or higher, the red diode lights up
